# Project 01 — Selections and transforms

## Aim
Selections and transforms.

## Tool / environment
Inkscape

## Files
original.svg → edited.svg; PNG previews

## Procedure
Open original.svg in Inkscape. Select the mountain or sun object with the selection tool. Duplicate it before editing. Scale using the corner handles, rotate using a second click, and flip horizontally from the toolbar. For the supplied final design, open edited.svg: the landscape is flipped, the label is rotated and scaled, and the scene is clipped to a rounded rectangle. Enter the group to edit individual objects. Export PNG from File → Export.

## Check your output
Compare original.png and edited.png. The final has a rounded crop, mirrored landscape and transformed label.

## Result and scope
The project demonstrates object selection, group transforms and clipping in an editable vector image.
