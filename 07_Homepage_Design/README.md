# Project 07 — Homepage with branding, table and quick links

## Aim
Homepage with branding, table and quick links.

## Tool / environment
Bluefish or another HTML editor

## Files
index.html, courses.html, about.html, lesson.html, logo.svg, banner.svg

## Procedure
Open index.html in Bluefish to edit the homepage source. Change the headline, schedule table or quick links. Open index.html in a browser to preview. Follow the links to the other pages. Each page embeds its CSS so it remains portable; styles.css is a reference copy for optional refactoring.

## Check your output
Check the banner, logo, schedule table and navigation. All assets are local; no CDN or account is required.

## Result and scope
The page covers homepage authoring with graphics, structured tabular content and quick links.
