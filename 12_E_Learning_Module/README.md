# Project 12 — Interactive e-learning module

## Aim
Interactive e-learning module.

## Tool / environment
Browser; SCORM 1.2-compatible LMS/authoring platform

## Files
index.html, imsmanifest.xml, digital_media_scorm.zip

## Procedure
Open index.html for the standalone course. Read both lessons and answer the quiz. For an LMS that supports SCORM 1.2, upload digital_media_scorm.zip as a course package. The manifest must remain at the archive root. Standalone mode provides immediate feedback; inside a compatible LMS the course sends its status and score using the SCORM API.

## Check your output
Try an incorrect answer, then SVG. The course shows corrective feedback and completion. LMS interoperability needs checking on your chosen platform; this is not a native EdApp, Moovly or CourseLab source file.

## Result and scope
A short course combines explanation, navigation, a knowledge check and SCORM completion reporting.
