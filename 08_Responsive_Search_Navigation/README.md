# Project 08 — Responsive website, navigation and search

## Aim
Responsive website, navigation and search.

## Tool / environment
Bluefish or another HTML editor

## Files
Four HTML pages, SVG assets and CSS reference

## Procedure
Open index.html and follow Courses. Type audio production in the search field: one course should remain. Clear it to restore all six. Search a word with no match to see the empty-result message. Open a course to navigate to lesson.html with its topic query parameter. Resize the browser to 390px wide, then to desktop width.

## Check your output
Use the keyboard to reach links and controls. On mobile the course grid becomes one column. Search is local catalogue filtering, not an internet search engine.

## Result and scope
Responsive layout, linked interior pages and accessible search feedback work together.
