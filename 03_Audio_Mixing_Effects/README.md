# Project 03 — Audio mixing and fades

## Aim
Audio mixing and fades.

## Tool / environment
Audacity

## Files
melody.wav, bass_and_beat.wav, import_tracks.lof, mixed_fades.wav

## Procedure
Open import_tracks.lof in Audacity to load the two source tracks, or use File → Import → Audio and select both WAV files. Both begin at zero. Select both tracks from 0 to 1.5 seconds and apply Fade In. Select 10 to 12 seconds and apply Fade Out. Mix and Render if desired; export WAV. Save your editable session as audio_mix.aup3. The supplied mixed_fades.wav is the pre-rendered reference mix.

## Check your output
Listen to each source and the final. The final should fade from silence, contain melody plus bass/beat and end smoothly without clipping.

## Result and scope
Two original synthesized tracks are mixed with controlled entry and exit. The .lof is an import list, not an .aup3 session.
