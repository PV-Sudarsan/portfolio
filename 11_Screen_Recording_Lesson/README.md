# Project 11 — Screen recording and e-learning editing

## Aim
Screen recording and e-learning editing.

## Tool / environment
Browser screen recorder; OpenShot for editing

## Files
lesson_to_record.html, recording_script.md, record_browser.cjs, raw_recording.webm, edited_lesson.mp4

## Procedure
Play edited_lesson.mp4. To make your own recording, open lesson_to_record.html and follow recording_script.md while using your desktop recorder. Import the raw recording into OpenShot, trim the opening, apply a short fade and export MP4. The included optional automation source record_browser.cjs captures the lesson with Playwright; follow its comments for installation and execution.

## Check your output
The recording should show the first lesson, second lesson, quiz selection and correct-answer feedback. The provided capture is an automated browser recording, not a recording of an authoring application.

## Result and scope
A browser lesson is turned into a short edited screencast; no spoken narration is included.
