# Recording storyboard
1. Open lesson_to_record.html at a 1280 × 720 browser viewport.
2. Show the first page for 3 seconds; point to the raster/vector explanation.
3. Select Next and explain WAV, MP3 and MP4 for 3 seconds.
4. Select Next, choose SVG and select Check answer.
5. Hold the completion result for 3 seconds.

The supplied raw recording is captured from an automated browser session of this exact page. It is not a manually performed desktop recording. edited_lesson.mp4 trims its opening, resizes to 960 × 540 and adds a fade. There is no spoken narration; optional narration text is given above.
