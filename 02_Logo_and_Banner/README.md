# Project 02 — Logo and homepage banner

## Aim
Logo and homepage banner.

## Tool / environment
Inkscape

## Files
logo.svg, banner.svg; matching PNG exports

## Procedure
Open logo.svg. Edit the name, tagline, symbol and background separately. Open banner.svg and change its text, gradient and play symbol. Keep enough contrast and spacing around the headline. Export the logo as PNG and the banner at 1440 × 500. The website projects use the editable SVG versions.

## Check your output
Both SVG files should open without external assets. Compare them with logo.png and banner.png.

## Result and scope
A consistent logo and banner give the sample website a shared visual identity.
